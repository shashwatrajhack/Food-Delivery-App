# 🍔 Food Delivery App

A modern, responsive **Food Delivery Web Application** built with React.js that lets users browse restaurants, explore menus, and discover food options — all in one place.

🌐 **Live Demo:** [https://foodlistingwebapp.netlify.app/](https://foodlistingwebapp.netlify.app/)

---

## 📸 Preview

![Food Delivery App](https://foodlistingwebapp.netlify.app/)

---

## ✨ Features

- 🏪 **Browse Restaurants** — Explore a list of restaurants with ratings and cuisine info
- 🔍 **Search Functionality** — Quickly find restaurants by name
- 📋 **Restaurant Menu** — View detailed menus for each restaurant
- 🛒 **Add to Cart** — Select food items and manage your cart
- 📶 **Online Status Detection** — Notifies users when they go offline
- ⚡ **Fast & Lightweight** — Bundled with Parcel for blazing-fast performance
- 📱 **Responsive Design** — Works seamlessly on desktop and mobile

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm (comes with Node.js)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/shashwatrajhack/Food-Delivery-App.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Food-Delivery-App
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm start
   ```

5. Open your browser and visit `http://localhost:1234`

---

## 🏗️ Build for Production

```bash
npm run build
```

The optimized output will be in the `dist/` folder.
